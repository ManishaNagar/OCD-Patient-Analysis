# 🧠 OCD Patient Data Analysis & Machine Learning Project

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) and Machine Learning on OCD (Obsessive-Compulsive Disorder) patient data to uncover meaningful clinical patterns, analyze symptom severity, and predict medication-related outcomes.

The project includes complete data preprocessing, feature engineering, visualization, model comparison, hyperparameter tuning, and feature importance analysis using Python.

This project demonstrates practical skills in:

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Machine Learning
* Model Evaluation
* Hyperparameter Tuning
* Data Visualization
* Clinical Data Analysis

# 📊 Project Workflow

## 1️⃣ Data Collection

* Imported OCD patient clinical dataset.

## 2️⃣ Data Preprocessing

* Removed unnecessary columns
* Handled missing values
* Cleaned dataset
* Encoded categorical variables
* Prepared data for machine learning

## 3️⃣ Feature Engineering

* Created Total OCD Severity Score using Y-BOCS scores
* Generated new analytical features

## 4️⃣ Exploratory Data Analysis (EDA)

* Distribution analysis
* Severity analysis
* Correlation analysis
* Gender-based comparison
* Statistical summaries

## 5️⃣ Data Visualization

* Histograms
* Box plots
* Correlation heatmaps
* Comparative analysis charts
* Confusion matrix visualization

## 6️⃣ Machine Learning

* Logistic Regression
* Random Forest Classifier
* Model comparison
* Accuracy evaluation
* Hyperparameter tuning using GridSearchCV

## 7️⃣ Feature Importance Analysis

* Identified important predictors influencing medication prediction
* Visualized feature importance scores
